# Security

Report a vulnerability in Multi Mail - the server at https://mail.lumman.co/mcp and https://lumman.co/mcp/mail, its sign-in, or the files in this repository - privately through GitHub: open this repository's Security tab and choose Report a vulnerability, or go to https://github.com/lumman-lab/multi-mail/security/advisories/new.

Say what you found, the steps that reproduce it and what it reaches. Only you and Lumman see the report.
